# Knowledge Base Backlog

Master list of gaps found by Agent 4 (Critic) during processing, Agent 5
(Curator) during wiki audits, Agent 6 (Consultant) during ticket triage, and
Agent 8 (Sentinel) during weekly code diff checks.
Entries are appended automatically; resolve them by writing/editing the raw
note and dropping it into `01_unprocessed/`.

Tags:

- `#verify` — prose and code contradict each other; needs a human ruling
- `#missing-info` — a concept/component is referenced but never explained
- `#open-question` — unresolved question (from a raw note or a Curator audit)
- `#missing-doc` — the wiki links to or relies on a document that does not exist yet
- `#ticket-gap` — a real ticket exposed missing knowledge base content
- `#stale-doc` — code changed since last Sentinel check; document may be outdated
- `#mis-tier` — Curator suspects the atom/molecule/organism classification is wrong; verify and correct frontmatter if so
