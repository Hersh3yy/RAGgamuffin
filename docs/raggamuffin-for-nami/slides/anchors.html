The cleverest safety trick

The AI suggests, the note decides

Each page can carry "anchors": the exact code names it is about. An anchor is only kept if those letters appear exactly in the real note. A tiny typo means it gets dropped and counted.

✓ IN THE NOTE, SO KEPT

app/Modules/Sepa/Models/Mandate.php

✗ AI TYPO, SO DROPPED

app/Modules/Sep:Sepa/Models/Mandate.php

A real AI once slipped in that extra colon. The check caught it. A wrong file path is worse than no path, because a wrong one looks confident and sends you to a door that doesn't exist.

This is the "hard part" Hiren is proudest of: the model proposes anchors, the source disposes. Verbatim means letter-for-letter.
