Honest moment: four of Hiren's own bugs

Found by trying it, not by reading it

Chopped too small

A note got sliced into 10 tiny scraps, so the AI invented ideas to fill the silence. Fix: bigger slices.

Skipped whole notes

A "skip the code" rule quietly skipped entire documents. Fix: only skip a scrap with almost no words.

Too strict, got nothing

The AI was told off so hard it returned empty. Fix: show it one worked example.

Proof came as waffle

The AI wrote sentences where code names belonged. Fix: a filter that only keeps real code shapes.

The lesson: you learn more by running the thing than by staring at it. All four bugs were invisible on paper and obvious the moment it ran on a real note. Ask Nami: have you ever been sure your homework was right until you actually tested it? What did the test teach you?
