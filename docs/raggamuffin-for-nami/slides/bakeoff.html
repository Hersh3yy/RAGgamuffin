The bake-off (bench.py)

A contest to pick the best brain

Several home-size AI brains get the same 3 notes and the same job. A scorecard grades each one, and Hiren adds his own 1-to-5 star rating. Run it again any time.

Did the proof match?

How many anchors were really in the note.

Any dead links?

Pages pointing to pages that don't exist.

How fast?

Words per second, so slow brains lose points.

So far the little qwen 4B blurts out the forbidden stuff; granite 8B is better but still calls plain section titles "ideas". The hunt for a smarter home brain is the open question.

This is like a cook-off where the same recipe is given to each chef and judged on a fixed scorecard. Programmers call the brains models. Ask Nami: if you were a judge, which would matter more to you, a brain that is fast, or one that never makes up fake links?
