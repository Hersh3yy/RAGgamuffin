The fix, in one sentence

Make the idea the thing you build, not the file

Old way: one note in, one note out, forever. A single idea living in six notes could never grow into its own page.

New way: read a note, pull out each separate idea (a "concept"), and give every concept its own page. Find that idea in another note tomorrow? Add to the same page instead of making a new one.

Six notes about signing now feed one page called Signing, stitched from all six. That is how scraps become a quilt.

This is the heart of the whole project: the unit changed from "document" to "concept". Programmers call the linked set of pages a knowledge graph. Ask Nami: if you kept one page per Pokemon and added to it every time a new game mentioned that Pokemon, versus starting a fresh page each time, which notebook is more useful?
