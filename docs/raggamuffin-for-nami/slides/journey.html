Inside the machine

One note's trip through RAGgamuffin

STOP 1

Cut up

The long note is sliced into bite-size chunks.

STOP 2 ✨AI

Name ideas

The AI reads a chunk and lists the concepts in it.

STOP 3

Fact-check

Every code name it gave is checked against the real note.

STOP 4

Merge

New page, or add to the page if that idea already exists.

STOP 5

Log it

The ledger writes down "this note is done".

Only Stop 2 uses AI. Stops 3, 4 and 5 are plain rules that give the same answer every time, so a careful robot guards the creative one.

Trace one note left to right. Programmers call stop 1 chunking and stop 5 the ledger. The key point: just one stop is the imaginative AI, and the boring reliable stops wrap around it. Ask Nami: why is it smart to let the AI suggest, but have a rule-checker decide what actually gets kept?
